## 2. 输入类型与判定（已决策 D1：内容嗅探 + 冲突让用户选）

### 2.1 支持的输入类型

| 类型 | 典型形态 | 入口 |
|---|---|---|
| **UUP 文件夹** | 目录内含文件清单 + 大量 `.cab` / `.esd` / `.msu`（可选 `ConvertConfig.ini`） | B |
| **ISO** | 安装介质镜像（含 `sources\install.*`、`setup.exe`、`boot\`、`efi\`） | C |
| **WIM** | 单一 `.wim`（可多索引/多 edition） | C |
| **ESD** | `.esd`（通常 LZMS 压缩；可能加密、可能分片） | C |
| **SWM** | `.swm` 分卷集合（`install.swm`、`install2.swm`…） | C（**拒绝**，见 §3.2） |

### 2.2 判定方法（按顺序，不依赖单一证据）

```
① 路径是目录？
   ├─ 命中 UUP 文件夹特征（存在文件清单 + ≥1 个 .cab/.esd/.msu）→ UUP 文件夹
   └─ 否则扫描目录内映像文件 → 进入 ③
② 路径是文件 → 读文件头
   ├─ 偏移 0 为 "MSWIM\0\0\0" → WIM 家族（再区分 WIM / ESD / SWM）
   ├─ 偏移 32769（0x8001）为 "CD001" → ISO9660（含 UDF 混合时同样命中）
   └─ 都不匹配 → 未知类型
③ WIM 家族细分
   ├─ 文件名匹配 install*.swm 或同目录存在 install2.swm 等兄弟分卷 → SWM（多卷）
   ├─ `wimlib info` 成功且压缩类型为 LZMS → 按 ESD 处理
   └─ 其余 → 按 WIM 处理
```

- **文件头优先于扩展名**：扩展名写错（如 `.iso` 实为 WIM）时按真实类型处理并记 `WARN extension_mismatch detected=<true> ext=<.iso>`。
- 文件头读取**固定 64 KB**：ISO 的 `CD001` 位于偏移 **32769**，读 32 KB（32768 字节）会正好差 6 字节而永远判不出 ISO，因此下限必须 ≥ 32774 字节，取 64 KB 留余量。只读文件头，不加载整个文件。
- 判定失败（读不到文件头/权限不足）→ `INPUT_UNREADABLE`，提示检查权限与文件占用。

### 2.3 冲突处理（不猜）

同一输入下出现**多个候选**时（例如目录里既有 ISO 又有 WIM，或 UUP 文件夹里混入了一个 ISO）：

| 情形 | 行为 |
|---|---|
| 目录同时命中 UUP 文件夹特征与映像文件 | 判为**冲突**：`INPUT_AMBIGUOUS`，列出全部候选（类型 + 路径 + edition 摘要），由用户选择 |
| 目录内有多个映像文件（2 个以上） | 同上，列出候选让用户选 |
| 单一候选 | 直接采用，记 `input_detected` |

- GUI：展示候选列表（类型、文件名、大小、edition 数），默认按「UUP 文件夹 > ISO > WIM/ESD」排序但**不自动选中**。
- CLI：`INPUT_AMBIGUOUS` 退出码 4，并在错误信息中列出候选路径，要求用户把输入改成具体文件或目录。

## 3. 能力与拒绝规则（已决策 D2/D3）

### 3.1 加密 ESD（D2：明确拒绝 + 引导）

- 判定：`wimlib info` 失败且错误包含 `encrypted`，或 `DISM /Get-WimInfo` 返回 `0x8007177A`（文件已加密）→ 判为加密 ESD。
- 判定不确定时**按加密处理**（保守），提示用户提供未加密映像。
- 行为：`INPUT_ENCRYPTED`（退出码 4），文案：「该映像已加密，本工具不解密。请提供未加密的 ESD、WIM 或 ISO。」
- **不尝试解密**：解密需密钥、成功率不稳定、失败会留下半成品。

### 3.2 多卷 SWM（D3：拒绝 + 合并指引）

- 判定：文件名 `install*.swm` 或同目录存在编号兄弟分卷。
- 行为：`INPUT_MULTI_VOLUME`（退出码 4），文案附合并指引：

  ```
  该输入为多卷 SWM（分卷映像），请先合并为单一 WIM：
    DISM /Export-Image /SourceImageFile:install.swm /SourceIndex:1 /DestinationImageFile:install.wim /Compress:max
  （若为 set 的后续分卷，需按 /SWMFile 参数逐个提供）
  ```

- **不自动合并**：需要额外磁盘与时间，失败会留下中间文件，且合并结果不受本工具校验。

### 3.3 分片 / 非独立 ESD

- 判定：`wimlib info` 输出含 `Part Number: n of m` 且 `m > 1`；或 `verify` 报告缺少数据块。
- 行为：`INPUT_FRAGMENTED`，提示「该 ESD 为非独立分片映像，无法单独导出；请改用完整 ISO 或组件聚合路径」。此结论与 `转换路线验证.md` 实测一致（单独导出报 `exit 55`）。

### 3.4 非安装介质 / 非 Windows 映像

| 判定 | 行为 |
|---|---|
| ISO 内缺 `sources\install.wim\|esd\|swm` 或缺 `setup.exe` | `INPUT_NOT_INSTALL_MEDIA`，提示「这不是 Windows 安装介质」 |
| WIM/ESD 内无 `Image Count ≥ 1` 或索引无 Windows 特征（`Windows`/`Microsoft` 目录） | `INPUT_NOT_WINDOWS`，拒绝 |
| 映像损坏（`info` 报 CRC/结构错误） | `INPUT_DAMAGED`，提示重新获取 |

- 拒绝一律**给出具体缺失项**，不返回「格式不支持」这类无法行动的空话。

## 4. 探测产物

`{程序目录}\work\<task_id>\input\probe.json`：

```json
{
  "schemaVersion": "1.0",
  "detectedAt": "2026-10-25T14:20:00+08:00",
  "type": "iso",
  "path": "D:\\ISO\\Win11_24H2.iso",
  "extensionMismatch": false,
  "encrypted": false,
  "multiVolume": false,
  "fragmented": false,
  "readOnlySource": true,
  "images": [
    { "index": 1, "name": "Windows 11 Pro", "description": "Windows 11 Pro", "edition": "professional", "arch": "x64", "lang": "zh-cn", "sizeBytes": 5123456789 }
  ],
  "bootable": true,
  "warnings": []
}
```

- `probe.json` 是**只读诊断产物**，不参与输出校验；
- `images[]` 必须完整（全部索引），供 GUI 的 edition 多选使用。

## 5. edition 枚举与选择

- 枚举方式：`wimlib info` 读取全部索引，取 `Index` / `Name` / `Description` / 大小；`edition` 由 `Name` 归一化（小写、去前后缀空格）。
- **全部索引都列出**，默认勾选第一个；用户可多选（多选时输出为多索引 WIM 或多份产物，按配置）。
- 无法归一化的名称标 `edition=unknown`，仍允许按 `index` 选择，记 `WARN edition_unknown index=<n> name=<...>`。
- 选择结果写入任务配置的 `TaskConfig.input.image.editions[]`（**索引号数组**），并与 `probe.json` 的索引表交叉校验；索引号不存在的选择直接判配置错误。
- 注意与 `TaskConfig.convert.editions[]`（**edition 名称数组**，见配置规范 §3.3）区分：前者是「从输入里选哪几个索引」，后者是「转换后保留哪些 edition 名」，两者在语义校验时互相交叉核对。

## 6. 起始阶段推断（FR0.1）

阶段名一律使用编排规范的 8 阶段（编排 §2）。「最早阶段」与「默认起点」是两件事：最早阶段是**技术上可行**的边界，默认起点是**产品体验**上的推荐值。

| 输入类型 | 支持的最早阶段（技术边界） | 默认起点（推荐） | 说明 |
|---|---|---|---|
| UUP 文件夹 | `Convert` | `Convert` | `Prepare` 只做 `probe`（枚举文件与清单），不做物化/解包 |
| ISO | `Prepare` | `Slim` | `Prepare.extract` 解包是硬前置；用户通常跳过「转换」 |
| WIM | `Prepare` | `Slim` | `Prepare` 只做 `probe`，WIM 直接引用不复制 |
| ESD | `Prepare` | `Slim` | `Prepare.materialize` 先物化为 LZX WIM，再进入 `Slim` |

- 规则：`requested_stage` 必须 **≥ 该输入支持的最早阶段**，否则 `STAGE_TOO_EARLY`（退出码 4），文案说明「该输入无法从 X 阶段开始，最早为 Y」。
- **`Prepare` 永不因起始阶段被跳过**：即使 `startStage=Slim`，`Prepare.probe` 与 `Prepare.materialize|extract` 仍执行；被跳过的是 `Fetch`/`Convert`（记 `skipped reason=input_satisfied`）。
- 「ESD 先导出为 LZX WIM」是 `Prepare.materialize` 子步骤，不是独立阶段（历史文档曾称 `Export`，已废弃），记 `event=esd_materialized`。
- 阶段定义与幂等性见 `任务编排与续跑规范.md`（§2/§3）。

## 7. 映像准备（`Prepare` 阶段，历史名 `PrepareImage`）

### 7.1 产物布局

| 输入 | 准备动作 | 产物 |
|---|---|---|
| ISO | 只读解包（`7z x`）到 `{work}\<task>\image\`；源 ISO 不动 | 完整文件树（`boot\`、`efi\`、`sources\`、`setup.exe`…） |
| WIM | **不复制**，直接引用源文件路径；需要修改时由后续阶段导出到工作文件 | `image\install.wim`（必要时） |
| ESD | `Prepare.materialize`：先导出为 LZX WIM | `image\install.wim`；媒体骨架与 `sources\boot.wim` **仅当该映像内含 `Windows Setup Media` 索引时**才自产——按索引 `Name` 与 `Boot Index` 判定，**不得假设「索引 1 = 骨架、索引 2 = boot.wim」**；不含该索引时要求用户提供 ISO，或按引擎规范 §6.3 回退 `full` |
| UUP 文件夹 | 不准备（由转换阶段接管） | — |

### 7.2 只读原则

- **原始输入永不修改**：ISO 只解包不原地改；WIM/ESD 只读打开；解包失败**不留半棵树**（解到 `image.tmp\` 再整体改名，规则同输出规范 §3）。
- 任何写操作落在 `{work}\<task>\` 内；若检测到对源路径的写意图 → `INPUT_IMMUTABLE_VIOLATION` 并中止（防御性断言）。

### 7.3 准备完成后的自检

1. `sources\install.wim|esd` 存在（ISO 路线）或 `image\install.wim` 存在（ESD 路线）；
2. `setup.exe`、`boot\etfsboot.com`、`efi\microsoft\boot\efisys.bin` 存在（ISO 路线）；
3. 目标 edition 的索引在 `install` 映像中可读；
4. 磁盘余量满足后续阶段（引用输出规范 §4 的预算表）。

任一项失败 → 阶段失败并给出具体缺失项，**不进入精简/优化**。

## 8. 输出类型选择（已决策 D4：允许只出 WIM/ESD）

| 输出类型 | 需要的阶段 | 说明 |
|---|---|---|
| **ISO**（默认） | `Output`（oscdimg） + 校验 | 完整安装介质 |
| **WIM** | 导出选中 edition，跳过封装 | 入口 C 常用；节省一次封装与 ISO 校验 |
| **ESD** | 导出为 LZMS | 保守模式下禁用 LZMS → 直接拒绝并说明原因 |
| **SWM** | 拆分 WIM（`DISM /FileSize`） | **后置能力**：契约保留取值但本期未验证，选择即 `OUTPUT_TYPE_UNSUPPORTED`；不产出半成品 |

- 入口 A/B 默认 ISO，但同样允许选 WIM（只做定制不出介质）；
- 输出类型与命名、伴生文件、校验分级的关系见 `输出校验与原子性规范.md`；
- 选择 ESD 输出且处于保守模式时，`OUTPUT_TYPE_UNSUPPORTED`，提示「当前工具版本能力未知，已禁用 ESD 输出，请改用 WIM」。

## 9. 拒绝与失败语义

| 错误 | 触发 | 退出码 | 用户可见文案要点 |
|---|---|---|---|
| `INPUT_UNREADABLE` | 无法读取文件头/被占用 | 4 | 检查权限与是否被其他程序占用 |
| `INPUT_UNSUPPORTED_TYPE` | 未知类型 | 4 | 列出扫描到的文件与支持的类型 |
| `INPUT_AMBIGUOUS` | 多个候选 | 4 | 列出候选路径，要求指定其一 |
| `INPUT_ENCRYPTED` | 加密 ESD | 4 | 需提供未加密映像 |
| `INPUT_MULTI_VOLUME` | 多卷 SWM | 4 | 附 DISM 合并命令 |
| `INPUT_FRAGMENTED` | 分片/非独立 ESD | 4 | 改用完整 ISO 或聚合路径 |
| `INPUT_NOT_INSTALL_MEDIA` | ISO 缺 install/setup | 4 | 指出缺失文件 |
| `INPUT_NOT_WINDOWS` | 非 Windows 映像 | 4 | 说明不支持 |
| `INPUT_DAMAGED` | 结构损坏 | 4 | 建议重新获取 |
| `STAGE_TOO_EARLY` | 起始阶段早于输入支持 | 4 | 给出最早可用阶段 |
| `OUTPUT_TYPE_UNSUPPORTED` | ESD 输出遇保守模式 | 4 | 建议改用 WIM |
| `INPUT_IMMUTABLE_VIOLATION` | 试图修改源 | 2 | 内部错误，附路径 |

## 11. 验收标准

1. **扩展名误标**：把 WIM 改名为 `.iso` → 仍识别为 WIM，记 `extension_mismatch`，不报「格式不支持」。
2. **冲突**：目录内同时放 ISO 与 WIM → 报 `INPUT_AMBIGUOUS` 并列出两个候选；GUI 默认不选中，CLI 退出码 4。
3. **UUP 文件夹**：含文件清单与 `.cab` 的目录识别为 UUP 文件夹；同目录混入 ISO 时按冲突处理。
4. **加密 ESD**：用加密样本 → `INPUT_ENCRYPTED`，文案含「不解密」，且**不产生**任何工作文件。
5. **多卷 SWM**：`install.swm` + `install2.swm` → `INPUT_MULTI_VOLUME`，文案含可执行的合并命令。
6. **分片 ESD**：用实测样本（`转换路线验证.md` 的 edition ESD）→ `INPUT_FRAGMENTED`，且不尝试导出。
7. **非安装介质**：普通数据 ISO → `INPUT_NOT_INSTALL_MEDIA` 并列出缺失的 `sources\install.*`。
8. **edition 枚举**：多索引 WIM → `probe.json` 列出全部索引；选择不存在的 index → 配置校验失败。
9. **ESD 输入**：ESD → 自动导出为 LZX WIM 并记住 `esd_materialized`，随后可进入精简阶段。
10. **起始阶段**：对 ISO 指定 `Convert` → `STAGE_TOO_EARLY`，文案给出最早阶段 `Slim`。
11. **只读**：准备完成后源 ISO 的修改时间与哈希不变；对源路径写入的尝试被 `INPUT_IMMUTABLE_VIOLATION` 拦截。
12. **输出类型**：入口 C 选 WIM 输出 → 不调用 oscdimg、产物为 `.wim` 且通过 L1/L2 校验；保守模式选 ESD → `OUTPUT_TYPE_UNSUPPORTED`。

## 12. 开放问题

- [ ] ESD 是否可直接挂载修改（跳过 materialize），需实测时间与稳定性对比。
- [ ] 多 edition 输出形态：一个多索引 WIM vs 每 edition 一份文件，需结合转换器与精简实现确定。
- [ ] ISO 解包用 `7z` 还是「只读挂载后复制」：UDF 长文件名与符号链接处理存在差异，需实测样本。
- [ ] 超长路径（>259）与网络路径（UNC）的支持边界。
- [ ] 是否需要「输入预检」独立命令（不做任务、只探测并输出 probe.json），便于排障。
