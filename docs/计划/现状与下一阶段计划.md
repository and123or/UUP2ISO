## 5. 版本号自动获取（新要求）

### 5.1 要解决的问题

现状：`26H2 = 26300` 这类映射只存在于人脑与文档里；若写进代码常量，一旦微软调整分支号（如 26H2 改 26300 → 26400）就要改代码、重发版。
目标：**版本族 → 主版本号** 由程序在运行时解析得出，**代码中零常量**。

### 5.2 范围界定（关键）

| 数据 | 来源 | 是否可自动获取 |
| --- | --- | --- |
| 版本族名（`26H2`） | 任务配置 / 用户选择 | — |
| **主版本号（`26300`）** | **GitHub 版本清单（动态解析）** | ✅ 本文要求 |
| 修订号（`9818`） | **输入数据本身**（UUP 文件名 / 清单 / `wimlib info` 的 `Version`） | ❌ 不由 GitHub 推断 |
| edition（`Professional`） | `wimlib info` 枚举 | ❌ |
| 输入类型（ISO/WIM/ESD/UUP） | 64 KB 文件头嗅探 | ❌ |

> 简言之：**GitHub 只回答"26H2 的主版本号是多少"**；"这份数据是 26300.9818"由数据自己回答。混用会导致把修订号也拿去猜。

### 5.3 获取方案

**通道（全部走 GitHub，符合"GitHub 为可信来源"）**

| 优先级 | 通道 | 说明 |
| --- | --- | --- |
| 1 | 配置的**官方仓库**（`versionCatalog.repos[0]`） | 运行时用 **GitHub Contents API 列目录**找最新 release 文件，**不写死路径**（避免微软调整目录结构就失效） |
| 2 | 配置的**镜像仓库**（`repos[1..n]`） | 社区维护的 Windows 版本清单（记录 repo + commit SHA） |
| 3 | **本地快照** `rules/windows_releases.json` | 上次成功抓取的结果，含 `source/commit/fetchedAt/sha256` |

> 实测记录（2026-11-02）：`api.github.com` 在本环境可达；本轮尝试的三个"官方清单"仓库路径均返回 404，因此**仓库与路径必须可配置 + 运行时发现**，不得在代码里假定。

**解析规则**

1. 抓取候选清单文件（Markdown/JSON 均可）→ 在文本中定位 `26H2` 与相邻的 5 位主版本号（`263\d\d`）。
2. 同一 family 需**至少两处一致**才采信；不一致记 `version_source_conflict` 并降级到快照。
3. 解析结果落 `cache/version/<owner>-<repo>-<commit>.json`，**TTL 24 小时**。
4. 失败降级：网络失败 → 用快照 + `WARN version_catalog_stale`；快照超过 90 天 → `WARN version_catalog_expired`（**不阻塞**，相关功能进"保守模式"）。

**审计字段**（写日志，不写配置）

```
event=version_resolved family=26H2 major=26300 source=<owner/repo>@<commit> fetchedAt=<ISO8601>
event=version_source_conflict family=26H2 values=26300,26400 fallback=snapshot
```

### 5.4 适用范围

| 用途 | 适用 | 说明 |
| --- | --- | --- |
| 无人值守 `autounattend.xml` 的组件版本映射 | ✅ | 由 `26H2 → 26300` 选出 `Microsoft-Windows-Setup` 等组件版本；解析不到则**拒绝生成**（现行规范） |
| 「保守模式」判定（`version=unknown`） | ✅ | 拿不到目录即 unknown → 禁 `--ref`/LZMS/未登记参数 |
| ISO 卷标与默认文件名 | ✅ | 用 `family`（26H2）+ `major`（26300），避免写死 `26100` |
| 规则库的 `version` 条件匹配 | ✅ | 规则里 `version: ">=26300"` 通过目录解析比较 |
| 诊断包 / 日志头 / `probe.json` 元信息 | ✅ | 记录"程序认定的版本族与主版本" |
| **输入映像类型识别** | ❌ | 用文件头嗅探（W1-T4），与版本无关 |
| **edition 枚举与选择** | ❌ | 用 `wimlib info` |
| **修订号（9818）与补丁级别** | ❌ | 来自输入数据/清单；GitHub 不提供"某个 UUP 数据集的修订号" |
| **是否 Ultimate/RTM 等发布状态** | ❌ | 属发布策略，不由本目录回答 |
| 离线环境 | ⚠️ 仅快照 | 无网时只能用快照；需在 UI 标注"版本信息可能过期" |
