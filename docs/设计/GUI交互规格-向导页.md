# UUP2ISO GUI 交互规格 · 向导页

> 版本：v0.2
> 分类：设计（交互规格） ｜ 目录：`docs/设计/`
> 依据：`需求分析.md` FR10.1（GUI 向导与页面）、FR0（三入口）、FR3–FR8（各阶段选项）
> 配套：`GUI与框架设计.md`（shell 与导航）、`预设与配置契约规范.md`（字段契约）、`精简与优化规则规范.md`（规则展示语义）、`输入识别与映像准备规范.md`（探测结果展示）

## 1. 全局交互规则

### 1.1 三档模式（简单 / 标准 / 专家）

| 档位 | 暴露范围 | 切换方式 |
|---|---|---|
| **简单** | 仅必填项与推荐项；所有选项用默认值 | 首次启动默认 |
| **标准** | 常用选项（各页 5–10 项） | 设置页或向导右上角 |
| **专家** | 全部选项，含危险项（仍需二次确认） | 同上 |

- 档位**持久化**到全局设置，不写入 `TaskConfig`（避免"配置决定界面"造成复现歧义）。
- 降档时已设置的专家项**不丢失**，只是隐藏；界面提示「有 3 项专家设置仍生效」。
- 字段表中的档位标记：`S` 简单可见、`N` 标准及以上、`X` 仅专家。

### 1.2 步骤条与跳转

- 顶部步骤条显示：`① 输入 → ② 构建 → ③ 下载 → ④ 转换 → ⑤ 精简 → ⑥ 优化 → ⑦ 集成 → ⑧ 无人值守 → ⑨ 输出 → ⑩ 确认`。
- **动态步骤**：按入口隐藏无关步骤（见 §3），隐藏的步骤不占位、不显示灰态。
- **回跳**：已完成（校验通过）的步骤可点击回跳；未完成的步骤不可跳（点击提示「请先完成当前步骤」）。
- **前跳风险**：回改前序步骤（如换 edition）导致后续选项失效时，在跳回时给出汇总提示「有 2 项设置因输入变化已重置」。
- 步骤完成状态只有两种：**已通过校验** / **未通过**；不做"部分完成"。

### 1.3 错误呈现（内联 + 底部汇总）

- **字段级**：输入框下方就地标红 + 一行说明（不弹窗）；
- **跨字段冲突**（如域加入 vs 自动登录）：显示在向导底部**汇总区**，每条可点击 → 滚动定位到相关字段并高亮；
- 汇总区默认折叠，存在错误时自动展开并显示计数「3 个问题需要处理」；
- 「下一步」按钮在存在错误时禁用，hover 提示「先处理 3 个问题」。

### 1.4 禁用态必须带原因

任何灰显控件都必须有 tooltip 说明原因，禁止只灰不说。典型文案：

- 「当前为离线模式，该规则需要在线系统」
- 「所选 edition 不支持该功能」
- 「工具版本未知（保守模式），已禁用 ESD 输出」

### 1.5 键盘与无障碍

| 交互 | 快捷键 |
|---|---|
| 下一步 / 上一步 | `Enter` / `Alt+←` |
| 开始执行 | `Ctrl+Enter`（仅在确认页） |
| 取消向导 | `Esc`（有未保存修改时二次确认） |
| 在汇总区问题间跳转 | `F8` / `Shift+F8` |

- 所有控件具备可读名称（屏幕阅读器）；焦点框可见；对比度符合 WCAG AA。
- Tab 顺序与视觉顺序一致；分组用 fieldset 语义（Qt 中用 `QGroupBox` + accessibleName）。

### 1.6 草稿与离开保护

- 进入向导第 1 步即生成 `taskId` 与草稿（写入 `tasks\<id>.json`，`status=draft`）。
- 切换步骤自动保存；关闭窗口时若有未保存变更 → 确认「保存草稿 / 放弃 / 取消」。
- 草稿不计入「最近 50 个任务」的清理优先级（草稿单独保留最近 10 个，见设置与对话框 §5）。

## 2. 页面总览

| 步骤 | 页面 | 关键产出 | 可跳过条件 |
|---|---|---|---|
| ① | 输入 | 入口、输入路径、起始阶段 | 不可跳过 |
| ② | 构建 | build / revision / 语言 / edition | 入口 C 隐藏 |
| ③ | 下载 | 文件清单与完成状态 | 入口 C 隐藏；本地已齐全可跳过 |
| ④ | 转换 | 转换模式、压缩类型 | 输入已是可编辑 WIM 时隐藏 |
| ⑤ | 精简 | 预设 + 规则选择 | 可选（全不选则跳过阶段） |
| ⑥ | 优化 | 预设 + 规则选择 | 可选 |
| ⑦ | 集成 | 更新/驱动/语言/注册表 | 可选 |
| ⑧ | 无人值守 | 模板与配置 | 可选 |
| ⑨ | 输出 | 类型、目录、命名、校验级别 | 不可跳过 |
| ⑩ | 确认 | 摘要与开始 | 不可跳过 |

## 3. 步骤页字段规格

### 3.1 ① 输入

| 字段 | 控件 | 默认 | 校验与提示 | 档 |
|---|---|---|---|---|
| 入口 | 三张单选卡片（在线构建 / 本地 UUP / 现成映像） | 在线构建 | 切换时清空后续步骤选择并提示 | S |
| 输入路径 | 文件/目录选择器 + 拖放区 | 空 | 路径存在、可读、类型可识别 | S |
| 探测结果 | 只读卡片（类型徽标、edition 数、加密/分卷标记） | — | 加密/多卷 → 红字 + 阻断 | S |
| 候选选择 | 列表（多候选时出现） | — | 必须选 1 个才能继续 | S |
| 起始阶段 | 下拉 | 按输入推断 | 早于输入支持的最早阶段 → 禁用该项并说明 | N |
| 起始阶段说明 | 帮助文本 | — | 显示"将从 X 阶段开始，前 N 步跳过" | S |

- 拖放区接受 `.iso` / `.wim` / `.esd` / 目录；拖入多个文件 → 判为多候选（`输入识别与映像准备规范.md` §2.3）。
- 探测在后台线程执行，显示骨架/加载态；探测失败给出可操作提示（检查权限/占用）。

### 3.2 ② 构建（入口 A）

| 字段 | 控件 | 默认 | 校验与提示 | 档 |
|---|---|---|---|---|
| 数据源 | 只读文本 + 「配置」链接 | 全局设置 | 不可用 → 红字提示并给「回退默认」 | S |
| 通道 | 下拉（Retail / Insider…） | Retail | 仅列可用通道 | S |
| 架构 | 下拉（x64 / arm64） | x64 | arm64 标注「未验证」 | N |
| 语言 | 下拉（多语言构建可多选） | 系统语言或 en-us | 至少 1 个 | S |
| 构建列表 | 表格（build / 发布日期 / 通道） | 最新 | 支持搜索；空列表 → 明确错误而非空白 | S |
| edition | 多选列表（来自详情） | 第一个 | 至少 1 个；显示名称与大小 | S |
| 刷新 | 按钮 + 缓存时间提示 | — | 过期缓存使用时标注「可能不是最新」 | S |

### 3.3 ③ 下载（入口 A/B）

| 字段 | 控件 | 默认 | 校验与提示 | 档 |
|---|---|---|---|---|
| 文件清单 | 表格（名称/大小/状态/重试次数） | — | 状态：待下/下载中/已校验/失败 | S |
| 总大小 | 文本 + 目标盘余量 | — | 余量不足 → 红字并禁用「下一步」 | S |
| 失败项 | 分组列表 + 「重试选中」 | — | 失败原因可展开（SHA1 不符显示期望/实际） | S |
| 连接数 | 数字输入 1–16 | 8 | 超范围不夹紧，直接报错 | X |
| 限速 | 数字输入（KB/s，0=不限） | 0 | — | X |
| 代理 | 地址/端口/账号/密码 | 空 | 凭据输入后仅显示 `***` | X |

- 下载中可「暂停并保存草稿」；离开页面需确认。
- 全部 `verified` 才允许「下一步」；允许「稍后继续」（保存草稿并退出向导）。

### 3.4 ④ 转换

| 字段 | 控件 | 默认 | 校验与提示 | 档 |
|---|---|---|---|---|
| 转换模式 | 单选（只出映像 / 完整 ISO） | 只出映像 | 无媒体骨架时自动回退完整 ISO 并提示 | N |
| 压缩类型 | 下拉（none/XPRESS/LZX/LZMS） | LZX | LZMS 在保守模式灰显 + 原因 | N |
| 保留中间产物 | 开关 | 关 | 开启后提示额外占用空间 | X |
| 预估 | 只读（耗时区间 / 空间） | — | 保守模式标注「估算可能不准」 | S |

### 3.5 ⑤ 精简

| 字段 | 控件 | 默认 | 校验与提示 | 档 |
|---|---|---|---|---|
| 预设 | 下拉（安全/标准/激进/自定义） | 安全 | 切换覆盖当前勾选并提示 | S |
| 分类树 | 树形多选（Appx / 组件 / 能力 / 硬件绕过） | 预设结果 | 每项显示风险徽标、体积 | S |
| 规则详情 | 右侧面板（名称、说明、警告、风险） | — | 高风险显示红色警告块 | S |
| 冲突提示 | 顶部条（可展开） | — | 列出被阻断项与原因，点击定位 | S |
| 跳过项 | 折叠区 | — | 「因上下文不满足跳过 2 项」+ 展开明细 | N |
| 高风险确认 | 勾选框 + 二次确认对话框 | 未勾 | 未确认的高风险项不参与执行 | S |
| 体积合计 | 只读文本 | — | 「预计减少 X GB」 | S |

- 规则列表来自规则库（只读），用户不能新增规则，只能勾选。
- 列表项禁用（依赖未满足/冲突/上下文不符）时，项仍可见并标注原因——**不隐藏**，否则用户会以为规则不存在。

### 3.6 ⑥ 优化

与精简同构，额外字段：

| 字段 | 控件 | 默认 | 校验与提示 | 档 |
|---|---|---|---|---|
| 不可逆项 | 列表（如 ResetBase） | 不勾 | 勾选需二次确认，文案含「不可撤销」 | N |
| 预计释放空间 | 按规则 `estimatedBytes` 汇总 | — | 缺 `estimatedBytes` 的项标「未估算」 | S |

### 3.7 ⑦ 集成

四个 Tab，任一 Tab 有内容即参与执行：

| Tab | 字段 | 校验 |
|---|---|---|
| 更新 | 添加文件/目录、列表（分类徽标 SSU/LCU/其他）、移除、查看顺序 | 非 `.msu/.cab` 拒绝；重复项自动去重并提示 |
| 驱动 | 添加目录、扫描结果（总数/已注入/未签名/冲突）、展开跳过清单 | 目录无 INF → 提示；未签名项列文件名与原因 |
| 语言 | LP / LIP / FOD 选择、当前 UI 语言只读显示 | 非法组合即时红字（如「缺少基础语言包」），阻断下一步 |
| 注册表 | 添加 `.reg`、hive 映射预览 | 无法映射的键 → 标红并说明该文件将被跳过 |

- 更新排序以只读列表展示（SSU → LCU → 其他），专家档可切「按我的顺序」并拖拽。
- 「查看执行计划」按钮：弹出只读清单（将应用哪些包/驱动/语言/注册表），不实际执行。

### 3.8 ⑧ 无人值守

| 字段 | 控件 | 默认 | 校验与提示 | 档 |
|---|---|---|---|---|
| 启用 | 开关 | 关 | 关闭时本页其余项禁用 | S |
| 模板 | 下拉（内置 4 套 + 导入…） | 桌面标准 | 导入需 XSD 通过 | S |
| 分区方案 | 单选（整盘 GPT / 自定义 / 保留现有） | 整盘 GPT | 自定义 → 展开分区表编辑器（专家） | N |
| 账户类型 | 单选（本地 / 域） | 本地 | 域加入 ⟂ 本地自动登录 | S |
| 本地账户 | 用户名 / 密码 / 确认 | 空 | 至少 1 个管理员；密码强度弱提示 | S |
| 自动登录 | 开关 | 关 | 开启必须填密码，并显示风险提示 | N |
| 域信息 | 域 / OU / 账号 / 密码 | 空 | 仅域模式可见 | N |
| 计算机名 | 输入 + 「随机」按钮 | 空 | ≤15 字符、非法字符校验 | N |
| 区域/语言/时区/键盘 | 四个下拉 | 取自构建语言 | 语言必须已在映像中（否则提示先集成） | S |
| 产品密钥 | 密码型输入 + 「不写入」开关 | 不写入 | 输入后仅显示末 5 位 | N |
| 脚本列表 | 表格 + 添加/移除 | 空 | ≤64 KB、≤3 个、禁交互命令（即时检测） | N |

### 3.9 ⑨ 输出

| 字段 | 控件 | 默认 | 校验与提示 | 档 |
|---|---|---|---|---|
| 输出类型 | 单选（ISO / WIM / ESD / SWM） | ISO | ESD 在保守模式灰显 + 原因；**SWM 恒灰显**（文案「分卷输出尚未验证，本期不支持」） | S |
| 输出目录 | 目录选择器（可空） | 空 = 全局默认 | 可写性检查；空间预检（产物 ×1.05） | S |
| 命名模板 | 输入 + 变量提示 + 实时预览 | `{edition}_{build}_{arch}_{lang}` | 非法字符自动替换并提示；预览显示最终名 | N |
| 重名策略 | 下拉（加后缀 / 询问 / 覆盖） | 加后缀 | 覆盖需二次确认；CLI 下「询问」等同后缀 | N |
| 校验级别 | 单选（结构 / +内容 / +深度） | 结构+内容 | 深度标注「可能 10–30 分钟」 | N |
| 伴生文件 | 复选（SHA256 / readme / 清单） | 前两项 | — | N |
| 空间提示 | 只读（需要 X GB / 可用 Y GB） | — | 不足 → 红字 + 阻断 | S |

### 3.10 ⑩ 确认

| 区块 | 内容 |
|---|---|
| 摘要 | 入口、构建/语言/edition、起始阶段、精简项数、优化项数、集成项数、输出类型与文件名预览 |
| 警告汇总 | 降级项（保守模式）、跳过项（上下文）、高风险项（已确认/未确认） |
| 预估 | 总耗时区间、所需空间、产物大小估计 |
| 操作 | 「保存配置」「仅生成计划（dry-run）」「开始」 |

- 「开始」仅在无错误时可用；存在未确认的高风险项时禁用并提示。
- 「仅生成计划」打开只读计划视图（阶段、命令、将复用产物），可导出为文本。

## 4. 页面状态

每页统一支持四种状态，布局不跳动：

| 状态 | 表现 |
|---|---|
| 空 | 说明文字 + 主操作按钮（如「选择文件」），不留空白面板 |
| 加载 | 骨架屏 + 可取消的进度指示（超过 1 秒才显示） |
| 错误 | 就地错误块（原因 + 可执行建议 + 重试按钮），不覆盖整页 |
| 禁用 | 控件灰显 + 原因 tooltip；整页禁用时显示解锁条件 |

## 5. 日志与进度联动

- 向导本身不展示实时日志；点击「开始」后跳转执行页（见设置与对话框 §6）。
- 执行页可在任务运行中返回向导查看配置，但**不可修改**（修改需新建任务）——按钮置灰并提示。

## 6. 验收标准

1. **档位**：简单档下 ①②③ 页字段数 ≤8；专家档显示全部；降档后专家项仍生效并在提示中可见。
2. **动态步骤**：入口 C 时步骤条不出现「构建」「下载」；起始阶段设为 Slim 时「转换」隐藏。
3. **回跳约束**：未完成步骤点击无响应并提示；回改 edition 后，失效的精简项被清空且给出汇总提示。
4. **错误呈现**：域加入 + 本地自动登录 → 底部汇总出现 1 条，点击后滚动到「自动登录」并高亮；该字段本身无内联错误（跨字段）。
5. **禁用原因**：保守模式下「ESD 输出」灰显，hover 显示「工具版本未知，已禁用 ESD 输出」。
6. **字段校验**：计算机名输入 16 字符 → 内联红字；命名模板含 `:` → 自动替换并提示。
7. **脚本限制**：添加第 4 个脚本 → 拒绝并提示上限；粘贴含 `pause` 的脚本 → 即时标红行号。
8. **空间预检**：输出盘剩余 1 GB、产物预计 5 GB → ⑨ 页红字阻断，「开始」不可用。
9. **草稿**：填写一半关闭窗口 → 选择「保存草稿」后重开，字段全部恢复且步骤停在原位置。
10. **键盘**：全程仅用键盘可完成向导（Tab/Enter/Alt+←）；焦点可见；汇总区可用 F8 跳转。
11. **未保存离开**：修改后按 Esc → 出现三选确认；选择「取消」留在原页。
12. **执行中返回**：任务运行时返回向导 → 控件全部只读，顶部提示「任务运行中，配置不可修改」。

## 7. 开放问题

- [ ] 分区编辑器（自定义分区）是否在 M2 就提供，还是先只提供「整盘 GPT」与「保留现有」。
- [ ] 精简/优化页的规则树是否需要「搜索规则」与「只看已选」筛选（规则数上百时）。
- [ ] 是否提供「配置对比」视图（当前配置 vs 预设默认）以解释差异。
- [ ] 向导是否需要「快速模式」一键到底（全部默认 + 只改输出目录）。
