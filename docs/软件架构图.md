        ISOB["OscdimgIsoBuilder"]
        PROC["ProcessRunner"]
        STORE["SettingsStore / PresetStore / ManifestCache"]
    end

    GUI --> Application
    CLI --> Application
    Application --> Core
    Infrastructure -.->|实现| Core
    ORCH --> PROG

    ORCH -.->|经 DI 注入接口| SRC
    ORCH -.->|经 DI 注入接口| DL

**依赖规则**：`Presentation → Application → Core ← Infrastructure`。依赖始终指向领域层，基础设施实现领域接口，组合根（Host/DI）负责装配。

## 11. 包依赖图（项目间）

```mermaid
flowchart TB
    GUI["UUP2ISO.Gui"] --> APP["UUP2ISO.Application"]
    CLIP["UUP2ISO.Cli"] --> APP
    APP --> CORE["UUP2ISO.Core"]
    APP --> INFRA["UUP2ISO.Infrastructure"]
    INFRA --> CORE
    TEST["UUP2ISO.*.Tests"] --> CORE
    TEST --> APP
```

- `Core` 无外部依赖（纯模型/接口）。
- `Application` 依赖 `Core`，通过接口使用 `Infrastructure`。
- `Gui`/`Cli` 仅依赖 `Application` 与 `Core`，不直接引用具体基础设施实现（由组合根装配）。
