## 2. 总体业务流程（三入口）

```mermaid
flowchart TD
    Start([开始]) --> Entry{选择输入源}
    Entry -->|A 在线构建| A1["查询构建列表 (FR1)"]
    A1 --> A2["选择构建/语言/版本"]
    A2 --> A3["生成文件清单"]
    A3 --> A4["aria2c 下载并校验 (FR2)"]
    A4 --> Conv["转换 (FR3)"]
    Entry -->|B 本地 UUP 文件夹| B1["读取本地清单/ConvertConfig"]
    B1 --> Conv
    Entry -->|C 现成 ISO/WIM/ESD| C1["识别并解包/挂载"]
    C1 --> Custom
    Conv --> Custom["精简/优化/集成 (FR4/FR5/FR6)"]
    Custom --> Unatt["无人值守定制 (FR7)"]
    Unatt --> Out["输出与校验 (FR8)"]
    Out --> Done([结束])
```

## 15. 任务状态机与断点续跑（FR9）

```mermaid
stateDiagram-v2
    [*] --> Created
    Created --> Planning: 选择入口与选项
    Planning --> Ready: 生成阶段计划
    Ready --> Running: 开始
    Running --> Running: 阶段进度
    Running --> Paused: 暂停(写检查点)
    Paused --> Running: 继续
    Running --> Cancelled: 取消
    Running --> Failed: 阶段失败
    Failed --> Running: 从失败阶段重试
    Running --> Succeeded: 输出校验通过
    Cancelled --> [*]
    Succeeded --> [*]
```

续跑：`CheckpointStore` 持久化当前阶段、已完成文件哈希与选项；重启后从检查点恢复（对应 `--resume`）。

## 17. 错误处理与重试（非功能・健壮性）

```mermaid
flowchart TD
    E0([阶段执行]) --> E1{"抛错?"}
    E1 -->|否| E2["返回成功"]
    E1 -->|是| E3["归类: 依赖/网络/工具/数据/权限"]
    E3 --> E4{"可重试?"}
    E4 -->|是| E5["按策略重试 N 次"]
    E5 --> E6{"仍失败?"}
    E6 -->|否| E2
    E6 -->|是| E7["标记阶段失败"]
    E4 -->|否| E7
    E7 --> E8["记录日志 + 返回码 + 涉及文件/工具"]
    E8 --> E9(["UI: 查看日志 / 重试本阶段 / 取消"])
```

退出码：0 成功｜1 完成但有警告｜2 阶段失败｜3 用户取消｜4 参数/依赖错误。
