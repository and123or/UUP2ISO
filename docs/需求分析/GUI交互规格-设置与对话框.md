# UUP2ISO GUI 交互规格 · 设置与对话框

> 版本：v0.1
> 依据：`需求分析.md` FR10.4（设置）、FR9.3–9.5（日志与诊断包）、FR9.1（任务配置）、FR4.4/FR5.6（预设）
> 配套：`GUI交互规格-向导页.md`（全局规则与三档模式）、`日志规范.md`、`数据源与下载规范.md`、`外部工具与进程执行规范.md`、`映像引擎与转换规范.md`、`预设与配置契约规范.md`
> 范围：设置页 6 个页签、预设管理、日志页、任务列表与执行页、对话框族。

---

## 1. 通用规则

- 设置页**不受三档模式影响**（全部可见）；只有向导页按档位收敛。
- 设置项保存即生效（无需重启），但运行中的任务使用启动时快照——界面提示「对当前运行任务不生效」。
- 所有设置项必须有默认值与「恢复默认」入口（单项 + 整页）。
- 修改需要写盘或校验的项（数据源地址、工具路径、日志阈值）在失焦或点击「应用」时校验，不实时打断输入。

## 2. 设置页

### 2.1 数据源

| 字段 | 控件 | 默认 | 校验 / 说明 |
|---|---|---|---|
| 主地址 | 文本（URL） | `https://uupdump.net/` | 必须 https；保存前「测试连接」探测端点 |
| 备用地址 | 列表（增删排序） | 空 | 按顺序回退；每条单独测试 |
| 缓存时效 | 只读文本 | 10 分钟（固定） | 与下载规范一致，不开放修改 |
| 测试连接 | 按钮 | — | 结果三态：成功（含响应时间）/ 失败（原因）/ 超时 |
| 恢复默认 | 按钮 | — | 二次确认 |

### 2.2 下载

| 字段 | 控件 | 默认 | 校验 / 说明 |
|---|---|---|---|
| 单文件连接数 | 数字 1–16 | 8 | 超范围直接报错（不夹紧） |
| 全局限速 | 数字 KB/s（0=不限） | 0 | — |
| 代理 | 类型下拉（无/HTTP/SOCKS5）+ 地址/端口/账号/密码 | 无 | 凭据仅显示 `***`；保存后不回显 |
| 网络重试 | 只读文本 | 3 次 / 退避 2s（固定） | 指向下载规范 |
| 校验失败重下 | 只读文本 | 最多 2 次（固定） | 同上 |

### 2.3 日志

| 字段 | 控件 | 默认 | 校验 / 说明 |
|---|---|---|---|
| 当前级别 | 只读（含来源） | INFO（发布版） | 来源：发布版 / 开发模式 / `--debug` |
| 日志目录 | 只读文本 + 「打开」 | `{程序目录}\logs` | 便携分发固定，不可改 |
| 运行日志阈值 | 大小 MB / 天数 / 数量 | 200 / 30 / 100 | 下限 10 MB / 1 天 / 5 个 |
| 审计日志阈值 | 大小 MB / 天数 / 数量 | 20 / 365 / 200 | 同上下限 |
| 立即清理 | 按钮 | — | 执行后报告「释放 X MB，删除 N 个文件」 |
| 生成诊断包 | 按钮 | — | 打开诊断包对话框（§7.5） |

- 说明文字必须写明「诊断包与运行日志共用同一阈值」。

### 2.4 工具与依赖

| 行 | 内容 | 状态显示 |
|---|---|---|
| `aria2c` | 版本、来源（tools/设置/PATH）、路径 | ✓ 已就绪 / ✗ 缺失（[获取]）/ ⚠ 版本高于清单 |
| `7-Zip` | 同上 | 同上 |
| `wimlib-imagex` | 同上 | 同上 |
| `DISM` | 系统内置 | ✓ / ✗ 需管理员 |
| `oscdimg` | 未找到时显示指引 | ✗ 未找到 → [安装 ADK 指引]（不自动获取） |
| 转换器 | 版本（锁定） | ✓ v1.0 随包 · **不参与自动更新** [查看说明] |

| 控件 | 默认 | 说明 |
|---|---|---|
| 工具自动更新 | 关闭 | 说明「按随包清单对齐版本，不追上游新版」；开启后仅在启动、任务开始前执行 |
| 立即对齐 | 按钮 | 手动触发一次版本对齐；结果逐项显示（已对齐/跳过/版本更高不回退/失败） |
| 重新获取 | 单项按钮 | 仅对缺失项可用 |

### 2.5 高级

| 字段 | 控件 | 默认 | 说明 |
|---|---|---|---|

## 3. 预设管理

| 区块 | 内容 |
|---|---|
| 左侧分类 | 精简 / 优化 / 集成 / 无人值守 |
| 列表 | 名称、版本、规则数、更新时间；支持搜索 |
| 操作 | 新建（基于当前任务配置）、重命名、复制、删除、导出、导入 |
| 右侧详情 | 规则清单（id + 名称 + 风险徽标）；未知或已删除规则标红 |

交互要点：

- **删除预设**不影响已保存任务（快照内联，见配置规范 §4.2），提示文案必须说明这一点。
- **导入**：`ruleId` 不存在 → 拒绝并列出缺失项；`presetVersion` 与当前规则库不匹配 → 允许导入但标「基于旧规则库」。
- **导出**：输出单个 JSON，文件名默认 `{kind}-{name}-{version}.json`。

## 4. 日志页

| 区块 | 内容 |
|---|---|
| 顶部 | 当前日志文件（只读路径）、级别、大小；「打开目录」「复制全部」「生成诊断包」 |
| 筛选 | 级别多选（DEBUG/INFO/WARN/ERROR/AUDIT）、阶段下拉、关键字搜索（支持 `k=v` 精确匹配） |
| 列表 | 时间、级别、阶段、消息、键值对（可折叠） |
| 底部 | 匹配条数、是否已截断提示（超 10 万行只显示最近部分并提示） |

- 审计日志在列表中单独标记（`AUDIT` 级别），来源为 `audit_*.log`，**以只读方式打开**（无编辑入口）。
- 「复制」默认只复制选中行；「复制全部」需确认（可能很大）。
- 日志页不提供「清空」（清理只在设置页）。

## 5. 任务列表

| 列 | 内容 |
|---|---|
| 状态 | 草稿 / 排队 / 运行中 / 已完成 / 失败 / 已取消 / 已中断 |
| 名称 | 任务名（默认 `{edition} {build} {time}`） |
| 输入 | 入口 + 简述（构建号或输入文件名） |
| 时间 | 开始时间、耗时 |
| 结果 | 产物名与大小（成功时）；失败时显示阶段与错误摘要 |
| 操作 | 继续（可续跑时）/ 查看日志 / 清理中间产物 / 删除记录 |

- 状态为「已中断」时首行提示「检测到未完成的任务，可继续」。
- **删除记录**：确认框明确写「删除任务记录与中间产物，不会删除已生成的 ISO 文件」。
- 草稿单独分组，默认折叠。
- 列表支持按状态筛选与按时间排序；空列表显示引导（「新建任务」按钮）。

## 6. 执行页

| 区块 | 内容 |
|---|---|
| 阶段串 | 8 个阶段横向排列，状态：等待/进行中/成功/失败/跳过（含原因 tooltip） |
| 总进度 | 进度条 + 百分比 + 预计剩余时间（无可靠估算时显示「估算中」） |
| 当前动作 | 工具名 + 子步骤 + 已耗时 |
| 日志面板 | 实时追加（仅 `line`/`result`，不含进度行）；可暂停滚动；「打开完整日志」跳日志页 |
| 操作 | 取消任务 / 重试本阶段（失败时）/ 打开输出目录（成功后） |

- 取消需二次确认，文案说明「已完成的中间产物会保留，可稍后继续」。
- 任务运行中关闭窗口 → 三选：最小化继续运行 / 取消任务并退出 / 返回。
- 执行页不提供配置修改入口（返回向导为只读，见向导页 §5）。

## 7. 对话框族

### 7.1 通用确认

标题 + 一句话说明 + 主/次按钮（主按钮文案具体，如「删除记录」而非「确定」）。

### 7.2 危险操作确认

用于：启用高风险规则、覆盖已有输出、注入未签名驱动、不可逆项（ResetBase）、删除任务记录。

结构：`警告图标 + 操作后果（具体到对象）+ 不可逆说明 + [取消] [我已了解，继续]`。
必要时附加勾选「我明白此操作不可撤销」，未勾选时主按钮禁用。

### 7.3 覆盖冲突

`目标文件已存在：D:\ISO\win11_26100_x64_zh-cn.iso` → 单选「加后缀保存（推荐）/ 覆盖 / 取消」，并显示两文件的大小与修改时间对比。

### 7.4 错误详情

| 区块 | 内容 |
|---|---|
| 摘要 | 错误码、阶段、一句话原因 |
| 详情 | 工具名、退出码、`hresult`、最后 20 行输出（脱敏） |
| 操作 | 复制详情 / 打开日志 / 打包诊断 / 关闭 |

- 不显示完整命令行中的敏感参数（代理凭据、密钥）。

### 7.5 诊断包

范围（当前任务 / 整个任务 = 含历史续跑日志）、保存目录（默认 `{程序目录}\logs`）、包含内容预览（脱敏后）、进度条；完成后「打开所在文件夹」。

### 7.6 退出确认

- 无运行任务：直接退出（有未保存草稿时提示保存）。
- 有运行任务：三选「取消任务并退出 / 最小化到后台继续 / 返回」。

## 8. 无障碍与一致性

- 所有对话框可用 `Esc` 关闭（危险确认除外，需显式选择）。
- 焦点默认落在**非破坏性**按钮上（避免误按「删除」）。
- 表格列可排序；列宽可拖拽；状态列使用「颜色 + 文本」双重编码（不依赖颜色）。
- 深/浅色主题均保证对比度；状态色不单独承载语义。

## 9. 验收标准

1. **设置即时生效**：修改日志阈值后立即清理 → 按新阈值执行；运行中的任务不受影响且有提示。
2. **数据源校验**：填入 `http://` 地址 → 拒绝并提示必须 https；测试连接失败给出原因与「恢复默认」。
3. **工具面板**：删除 `aria2c` 后打开设置 → 显示 ✗ 与「获取」按钮；点击后自动下载并显示结果。
4. **自动更新语义**：开关说明文字包含「不追上游新版」；本地工具被手工替换为新版 → 点「立即对齐」后显示「版本高于清单，不回退」。
5. **日志页**：审计日志行带 `AUDIT` 标记且无编辑入口；关键字 `exit=55` 能精确匹配到对应行。
6. **预设删除**：删除被任务引用的预设 → 弹窗说明「已保存任务不受影响」，删除后旧任务仍可运行。
7. **预设导入**：导入含未知 `ruleId` 的预设 → 拒绝并列出缺失 id。
8. **任务列表**：删除记录 → 提示明确「不会删除 ISO」；执行后中间目录消失、输出目录产物仍在。
9. **执行页**：取消任务 → 二次确认后阶段变「已取消」，中间产物保留，列表显示「可继续」。
10. **错误详情**：`wimlib` 返回 55 → 详情含 `exit=55`、最后 20 行、可复制；无敏感参数。
11. **危险确认**：勾选高风险规则后未勾「我已了解」→ 主按钮禁用。
12. **关闭窗口**：任务运行中关闭 → 三选出现；选「最小化」后任务继续运行且进度不中断。

## 10. 开放问题

- [ ] 是否需要系统托盘（最小化到托盘继续运行），当前为「最小化窗口」。
- [ ] 设置项是否支持「导出/导入」（便于多机同步），与便携分发下的目录复制是否重复。
- [ ] 任务列表是否需要分组（按日期/状态）与批量清理。
- [ ] 是否需要为高级阈值（CPU/磁盘/网络空闲）提供「一键校准」向导。
