# UUP2ISO 项目计划

> 版本：v0.19（草案）
> 技术栈：Python 3.12+（PySide6 GUI / PyInstaller 打包），Windows 10/11 x64
> 依据：`docs/需求分析.md`（FR0–FR10）、`docs/GUI与框架设计.md`、`docs/软件架构图.md`、`docs/软件流程图.md`、`docs/FR3-FR5详细需求.md`、`docs/日志规范.md`、`docs/外部工具与进程执行规范.md`、`docs/映像引擎与转换规范.md`、`docs/输出校验与原子性规范.md`
> 说明：本计划采用「里程碑（M）→ 工作包（WS/WP）→ 任务（T）」的 WBS。当前版本先冻结范围、依赖和验收门禁；正式排期前必须补充负责人、估算、日期、关键路径和验收环境。

## 1. 计划说明

### 1.1 组织方式

| 层级 | 含义 | 编号 |
|---|---|---|
| 里程碑 | 可发布的阶段性成果，对齐需求文档「12. 分期里程碑」 | `M0`–`M4` |
| 工作包 | 相对独立的交付单元（对应一个模块或需求域） | `WS0`–`WS11` |
| 任务 | 可执行、可验收的最小工作项 | `WPn-Tm` |

每个任务包含：**描述 / 交付物 / 依赖 / 关联需求 / 验收要点**。

### 1.2 优先级与依赖约定

- 优先级沿用需求文档：**P0**（MVP 必须）、**P1**（二期必须）、**P2**（三期及以后）。
- 依赖以任务编号表示；未列依赖的任务可并行。
- 「完成」的定义（DoD）见 §7。

### 1.3 与需求文档的对应

- 里程碑 M0–M4 与需求文档 §12「分期里程碑」一致（M0 为工程基线，属 MVP 前置）。
- 功能域与 FR 编号一一映射，见 §6 追溯矩阵。

## 2. 项目范围与交付目标

### 2.1 范围（In Scope）

多入口流水线（A 在线构建 / B 本地 UUP 文件夹 / C 现成 ISO·WIM·ESD）；数据源可配、aria2c 专用下载；转换与 ISO 组装（对齐 `uup-converter-wimlib`）；精简（Appx/组件/硬件检查）；离线空间回收与注册表优化；集成（更新/驱动/语言包/注册表）；无人值守定制；输出校验；配置/日志；GUI 向导 + CLI。入口 B/C、虚拟版本、加密 ESD 和多分卷输入必须以技术验证结果为准。

### 2.2 范围外（Out of Scope）

在线激活/授权校验、任何绕过授权逻辑、驱动库商业化。产品不内置虚拟机创建、启动和自动安装编排；开发与发布验收可使用外部虚拟机环境。

### 2.3 最终交付物

| 类别 | 交付物 |
|---|---|
| 代码 | Python 工程（`pyproject.toml` + `src/` 布局）：core / application / infrastructure / gui / cli + `tests/`；依赖锁定文件 |
| 应用 | GUI 便携绿色包（x64，PyInstaller 单目录 + `--uac-admin` 提权，解压即用）、最小 CLI 可执行（`run --config` / `--dry-run` / `--resume`，含退出码与 JSON 输出） |
| 数据 | 精简/优化规则库（复用 `docs/需求分析/rules/*.json` + 全量扩充）、内置外部工具（可选） |
| 文档 | 需求/设计/架构/流程/详设/日志规范/进程执行规范/映像引擎规范/输出原子性规范/项目计划/用户手册 |
| 质量 | 单元/集成/端到端测试与兼容性矩阵报告 |

## 3. 里程碑总览

| 里程碑 | 主题 | 目标成果 | 对应 FR | 优先级 |

## 7. Definition of Done（任务级）

1. 代码在 `.venv` 虚拟环境内通过 lint/静态检查（`ruff check`、`ruff format --check`、`mypy`），无新增警告。
2. 有对应的单元或集成测试，且在 CI（`.venv` 内 `pytest`）通过。
3. 关联需求（FR 条目）的**验收标准**全部满足。
4. 外部工具交互经 `ProcessRunner`；**关键输出（启动/结束/返回码/警告）入日志，进度只显示不落盘**（`日志规范.md` §5.2）。
5. 错误路径有明确错误类型与退出码；不产出半成品。
6. 高风险/删除性操作有二次确认与日志留痕。
7. 相关文档（需求/设计/规则库）同步更新。

| 输出盘空间不足导致长任务末尾失败 | WP8-T4 | 两段预检（Fetch 前、Output 前）+ 提前失败并给出所需/可用空间；暂存区不创建 |
| 崩溃/断电产生半成品被误用 | WP8-T4 | 同卷暂存 + 原子 rename + 提交后复核；`.part` 永不进入最终名，也不参与续跑复用 |
